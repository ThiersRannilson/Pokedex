Desenvolvi uma Pokédex completa da 1ª Geração do zero até ao deploy em produção.

🚀 Tecnologias Utilizadas
HTML5 para a estrutura semântica.

Tailwind CSS para a estilização moderna e design responsivo.

JavaScript (Vanilla) para toda a lógica da aplicação e manipulação do DOM.

PokéAPI para o consumo de dados em tempo real.

Firebase Hosting para o alojamento e publicação na nuvem.

Git e GitHub para o controlo de versões e portfólio.

💡 O que Aprendi e Pratiquei
Consumo de APIs Assíncronas: Dominei o uso de fetch, async/await e Promise.all para carregar e gerir os 151 Pokémon de forma eficiente.

Manipulação do DOM: Criei elementos dinamicamente e construí um sistema de cards e modais interativos.

Filtros em Tempo Real: Implementei uma lógica combinada para filtrar os Pokémon simultaneamente por nome e por tipo.

UI/UX e Responsividade: Apliquei conceitos de Mobile-First com Tailwind CSS (como grelhas adaptativas e scroll horizontal para ecrãs pequenos) e construí um modal detalhado com barras de progresso de estatísticas base, peso, altura e habilidades.

Ciclo de Desenvolvimento (DevOps): Estruturei o código de forma modular e fiz o deploy completo da aplicação para a nuvem.
